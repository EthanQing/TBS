# 智能训练平台后端 API 文档

## 1. 文档说明

本文档为智能训练平台（Train Platform）后端服务的 HTTP/WebSocket API 参考，适用于前端、外部标注平台、部署网关和第三方系统集成。

当前后端应用在 `train_platform/app.py` 中注册 `train_platform.api.v3`，统一 API 前缀为 `/api/v3`。本文档按 2026-06-13 当前代码核对；如果文档与代码冲突，以 `TBS/train_platform/api/v3/`、`TBS/train_platform/schemas/v3/` 和 `TBS/train_platform/services/v3/` 为准。

## 2. 基础信息

| 项目 | 说明 |
|------|------|
| Base URL | `http://<host>:<port>/api/v3` |
| 健康检查 | `GET /health` |
| 协议 | HTTP/1.1 + WebSocket |
| 数据格式 | JSON；上传接口使用 `multipart/form-data` |
| 字符编码 | UTF-8 |
| API 版本 | v3 |
| 框架 | FastAPI |

## 3. 通用约定

### 3.1 请求方法

| 方法 | 语义 |
|------|------|
| `GET` | 查询资源、列表、下载或静态流 |
| `POST` | 创建资源、上传、触发动作或异步任务 |
| `PUT` | 替换资源或上传分片 |
| `PATCH` | 局部更新资源 |
| `DELETE` | 删除资源、取消会话或清除配置 |

### 3.2 分页

分页接口通常使用以下 Query 参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `page` | int | 1 | 页码，最小值 1 |
| `page_size` | int | 50 | 每页条数，通常限制为 1~500 |

分页响应结构：

```json
{
  "items": [],
  "meta": {
    "page": 1,
    "page_size": 50,
    "total": 0
  }
}
```

### 3.3 响应与错误

常见成功状态码：

| 状态码 | 说明 |
|--------|------|
| `200` | 查询、更新或动作成功 |
| `201` | 创建成功 |
| `202` | 已接受异步任务 |

删除响应通常为：

```json
{
  "ok": true,
  "message": "Resource deleted"
}
```

常见错误状态码：

| 状态码 | 说明 |
|--------|------|
| `400` | 参数校验错误 |
| `401` | 鉴权失败或缺少 API Key |
| `404` | 资源不存在 |
| `409` | 当前状态不允许执行操作 |
| `500` | 服务端内部错误 |

错误响应由全局异常处理器返回，通常包含 `detail` 或 `message` 字段：

```json
{
  "detail": "Training run not found"
}
```

### 3.4 时间与 ID

- 时间字段使用 ISO 8601 字符串，例如 `2026-06-13T10:00:00+00:00`。
- 训练任务、上传任务、推理任务、部署运行等作业型资源通常使用字符串 UUID。
- 标准数据集、违规数据集、项目、模型版本等实体通常使用整数 ID。

### 3.5 主要枚举

任务类型：

- `detection`
- `segmentation`
- `classification`

训练任务状态：

- `created`
- `queued`
- `running`
- `completed`
- `failed`
- `cancelled`
- `deleted`

模型阶段：

- `development`
- `testing`
- `production`
- `deprecated`

部署状态：

- `pending`
- `deploying`
- `active`
- `inactive`
- `failed`
- `deleting`

部署运行状态：

- `queued`
- `running`
- `completed`
- `failed`
- `cancelled`

日志级别：

- `DEBUG`
- `INFO`
- `WARNING`
- `ERROR`

## 4. 静态资源

静态资源不带 `/api/v3` 前缀：

| URL 前缀 | 说明 |
|----------|------|
| `/static/datasets/` | 标准数据集文件 |
| `/static/thumbnails/` | 缩略图缓存 |
| `/static/training/` | 训练产物、日志和权重 |
| `/static/temp/` | 临时文件、上传和转换产物 |
| `/static/pretrain/` | 预训练模型 |

缩略图 API 位于 `/api/v3/thumbnails/...`，详见 [11_辅助接口.md](11_辅助接口.md)。

## 5. 健康检查

```http
GET /health
```

响应：

```json
{
  "ok": true
}
```
