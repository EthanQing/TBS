# 辅助接口 API

本文档涵盖平台辅助性 API：网络架构、框架插件、预训练模型上传、缩略图、图表配置和平台统计。所有接口均使用 `/api/v3` 前缀。

---

## 一、网络架构

> **路由前缀：** `/api/v3/architectures`
> **标签：** `architectures`

### 1. 获取架构列表

```http
GET /api/v3/architectures?family=yolo&task_type=detection&engine=ultralytics-yolo&q=yolov8
```

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `family` | string | 否 | 按模型族过滤，如 `yolo` |
| `task_type` | string | 否 | `detection` / `segmentation` / `classification` |
| `engine` | string | 否 | 训练引擎插件 ID，如 `ultralytics-yolo` / `paddle-det` |
| `q` | string | 否 | 搜索关键词 |

响应示例：

```json
[
  {
    "architecture_id": 1,
    "family": "yolo",
    "variant": "yolov8n",
    "task_type": "detection",
    "engine": "ultralytics-yolo",
    "pretrained_path": null,
    "description": "YOLOv8 Nano 目标检测模型",
    "default_params": {
      "imgsz": 640
    },
    "created_at": "2026-06-13T10:00:00+08:00"
  }
]
```

### 2. 创建架构

```http
POST /api/v3/architectures
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `family` | string | 是 | - | 模型族 |
| `variant` | string | 是 | - | 模型变体 |
| `task_type` | string | 是 | - | 任务类型 |
| `engine` | string | 否 | `ultralytics-yolo` | 训练引擎 |
| `pretrained_path` | string? | 否 | `null` | 预训练权重路径或 token |
| `description` | string? | 否 | `null` | 描述 |
| `default_params` | object? | 否 | `null` | 默认训练参数 |

响应模型同 `ArchitectureOut`。

## 二、框架插件

> **路由前缀：** `/api/v3/frameworks`
> **标签：** `frameworks`

### 1. 获取框架列表

```http
GET /api/v3/frameworks?implemented=true
```

| 参数 | 类型 | 说明 |
|------|------|------|
| `implemented` | bool? | 按实现状态过滤；不传返回全部 |

响应示例：

```json
[
  {
    "plugin_id": "ultralytics-yolo",
    "name": "ultralytics-yolo",
    "display_name": "Ultralytics YOLO",
    "implemented": true,
    "config_schema": {
      "type": "object",
      "properties": {}
    }
  }
]
```

### 2. 获取框架配置 Schema

```http
GET /api/v3/frameworks/{plugin_id}/config-schema
```

响应示例：

```json
{
  "plugin_id": "ultralytics-yolo",
  "config_schema": {
    "type": "object",
    "properties": {
      "epochs": {
        "type": "integer",
        "default": 100
      }
    }
  }
}
```

### 3. 校验并规范化框架配置

```http
POST /api/v3/frameworks/{plugin_id}/validate-config
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `config` | object | 否 | 待校验配置，默认 `{}` |

响应示例：

```json
{
  "plugin_id": "ultralytics-yolo",
  "normalized_config": {
    "epochs": 100,
    "batch_size": 16
  }
}
```

该接口返回规范化后的配置；当前响应模型不包含 `valid` 或 `warnings` 字段。

## 三、预训练模型上传

> **路由前缀：** `/api/v3/pretrain-models`
> **标签：** `pretrain-models`

### 上传预训练权重

```http
POST /api/v3/pretrain-models/upload
Content-Type: multipart/form-data
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `file` | File | 是 | 权重文件，支持 `.pt` / `.pth` / `.ckpt` |

响应示例：

```json
{
  "token": "pretrain_uploads/model-abc123.pt",
  "path": "/static/temp/pretrain_uploads/model-abc123.pt",
  "filename": "model.pt"
}
```

返回的 `token` 可在创建训练任务时作为预训练权重引用。上传文件保存在临时目录下。

## 四、缩略图

> **路由前缀：** `/api/v3/thumbnails`
> **标签：** `thumbnails`

### 获取缩略图

```http
GET /api/v3/thumbnails/{dataset_kind}/{dataset_id}/{file_path}?size=200
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `dataset_kind` | string | - | 当前标准数据集使用 `standard`；违规数据集缩略图已禁用 |
| `dataset_id` | int | - | 数据集 ID |
| `file_path` | string | - | 图片相对路径，如 `images/train/001.jpg` |
| `size` | int | `200` | 缩略图最大边长，范围 `16` 到 `1024` |
| `version_id` | int? | `null` | 历史兼容参数；违规数据集缩略图仍会返回未找到 |

响应：图片二进制流，`Content-Type` 由缩略图文件类型决定，如 `image/webp` / `image/jpeg`。

示例：

```http
GET /api/v3/thumbnails/standard/2000001/images/train/img_001.jpg?size=200
```

## 五、图表配置

> **路由前缀：** `/api/v3/chart-configs`
> **标签：** `chart-configs`

用于持久化前端图表配置，如指标选择、坐标轴范围等。

### 1. 获取配置

```http
GET /api/v3/chart-configs/{scope}
```

未保存过该 scope 时返回空对象 `{}`。

### 2. 保存配置

```http
PUT /api/v3/chart-configs/{scope}
Content-Type: application/json
```

请求体可以是任意 JSON 对象：

```json
{
  "metrics": ["map50", "loss"],
  "smooth": true
}
```

响应：

```json
{
  "ok": true
}
```

## 六、平台统计

> **路由前缀：** `/api/v3/stats`
> **标签：** `stats`

### 获取平台汇总统计

```http
GET /api/v3/stats/summary
```

响应示例：

```json
{
  "datasets": 15,
  "projects": 8,
  "training_runs_total": 120,
  "training_runs_by_status": {
    "created": 2,
    "queued": 1,
    "running": 3,
    "completed": 95,
    "failed": 15,
    "cancelled": 4
  },
  "model_versions": 45,
  "deployments": 10,
  "deployments_active": 5
}
```

### StatsSummary

| 字段 | 类型 | 说明 |
|------|------|------|
| `datasets` | int | 标准数据集与违规数据集总数 |
| `projects` | int | 项目总数 |
| `training_runs_total` | int | 训练任务总数 |
| `training_runs_by_status` | object | 按状态分组的训练任务数量 |
| `model_versions` | int | 模型版本总数 |
| `deployments` | int | 部署总数 |
| `deployments_active` | int | 活跃部署数量 |

## 数据模型

### ArchitectureOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `architecture_id` | int | 架构 ID |
| `family` | string | 模型族 |
| `variant` | string | 模型变体 |
| `task_type` | string | 任务类型 |
| `engine` | string | 训练引擎插件 ID |
| `pretrained_path` | string? | 默认预训练权重 |
| `description` | string? | 描述 |
| `default_params` | object? | 默认参数 |
| `created_at` | datetime | 创建时间 |

### FrameworkPluginOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `plugin_id` | string | 插件 ID |
| `name` | string | 插件名称 |
| `display_name` | string | 展示名称 |
| `implemented` | bool | 是否已实现 |
| `config_schema` | object | 配置 schema |

### PretrainUploadOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `token` | string | 训练接口可引用的临时 token |
| `path` | string | 静态访问路径 |
| `filename` | string | 原始文件名 |
