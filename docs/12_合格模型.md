# 合格模型 API (Qualified Models)

> 路由前缀：`/api/v3/qualified-models`
> 标签：`qualified-models`

合格模型是用户对某个模型版本的人工确认记录。它用于把“训练完成且已注册”的模型版本标记为可进入后续部署、归档或评审流程的候选资产。

## 1. 获取合格模型列表

```http
GET /api/v3/qualified-models
```

Query 参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `page` | int | 否 | 1 | 页码 |
| `page_size` | int | 否 | 50 | 每页条数，1~500 |
| `project_id` | int | 否 | - | 按项目过滤 |
| `standard_dataset_id` | int | 否 | - | 按标准数据集过滤 |
| `run_id` | string | 否 | - | 按训练任务 ID 过滤 |
| `model_version_id` | int | 否 | - | 按模型版本 ID 过滤 |

响应示例：

```json
{
  "items": [
    {
      "qualified_model_id": 1,
      "model_version_id": 10,
      "project_id": 1,
      "run_id": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40",
      "standard_dataset_id": 2000001,
      "qualified_by": "admin",
      "note": "精度和推理耗时满足当前验收标准",
      "metrics": {
        "metrics/mAP50(B)": 0.85
      },
      "weights_path": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40/weights/best.pt",
      "created_at": "2026-06-13T03:10:00+00:00",
      "updated_at": "2026-06-13T03:10:00+00:00"
    }
  ],
  "meta": {
    "page": 1,
    "page_size": 50,
    "total": 1
  }
}
```

## 2. 标记模型为合格

```http
POST /api/v3/qualified-models
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model_version_id` | int | 是 | 要标记为合格的模型版本 ID |
| `qualified_by` | string | 否 | 操作人，最长 128 字符 |
| `note` | string | 否 | 备注，最长 2000 字符 |

请求示例：

```json
{
  "model_version_id": 10,
  "qualified_by": "admin",
  "note": "精度和推理耗时满足当前验收标准"
}
```

响应示例：

```json
{
  "created": true,
  "message": "模型已标记为合格",
  "item": {
    "qualified_model_id": 1,
    "model_version_id": 10,
    "project_id": 1,
    "run_id": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40",
    "standard_dataset_id": 2000001,
    "qualified_by": "admin",
    "note": "精度和推理耗时满足当前验收标准",
    "metrics": {
      "metrics/mAP50(B)": 0.85
    },
    "weights_path": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40/weights/best.pt",
    "created_at": "2026-06-13T03:10:00+00:00",
    "updated_at": "2026-06-13T03:10:00+00:00"
  }
}
```

幂等行为：同一个模型版本已经被标记为合格时，请求不会重复创建记录，响应中 `created=false`，`message` 为“该模型已标记为合格，无需重复操作”。

## 3. 获取合格模型详情

```http
GET /api/v3/qualified-models/{qualified_model_id}
```

路径参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `qualified_model_id` | int | 合格模型记录 ID |

## 4. 数据模型

### QualifiedModelOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `qualified_model_id` | int | 合格模型记录 ID |
| `model_version_id` | int | 模型版本 ID |
| `project_id` | int | 项目 ID |
| `run_id` | string | 来源训练任务 ID |
| `standard_dataset_id` | int | 标准数据集 ID |
| `qualified_by` | string? | 标记人 |
| `note` | string? | 备注 |
| `metrics` | object? | 模型指标快照 |
| `weights_path` | string? | 权重相对路径 |
| `created_at` | datetime | 创建时间 |
| `updated_at` | datetime | 更新时间 |
