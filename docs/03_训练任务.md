# 训练任务 API (Training Runs)

> 路由前缀：`/api/v3/training-runs`
> 标签：`training-runs`、`training-reports`

训练任务管理从创建、排队、执行、指标采集、日志流、报告生成到模型导出的完整生命周期。训练任务只引用项目，标准数据集来自项目绑定的 `standard_dataset_id`。

## 1. 获取训练任务列表

```http
GET /api/v3/training-runs
```

Query 参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `page` | int | 否 | 1 | 页码 |
| `page_size` | int | 否 | 50 | 每页条数，1~500 |
| `project_id` | int | 否 | - | 按项目过滤 |
| `standard_dataset_id` | int | 否 | - | 按标准数据集过滤 |
| `architecture_id` | int | 否 | - | 按模型架构过滤 |
| `status` | string | 否 | - | `created` / `queued` / `running` / `completed` / `failed` / `cancelled` / `deleted` |
| `include_hidden` | bool | 否 | false | 是否包含隐藏任务 |

响应：分页 `TrainingRunOut`。

## 2. 创建训练任务

```http
POST /api/v3/training-runs
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `project_id` | int | 是 | 项目 ID |
| `architecture_id` | int | 是 | 模型架构 ID |
| `name` | string | 否 | 任务名称，最长 255 字符 |
| `parameters` | object | 是 | 训练参数 |

`parameters` 字段：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `epochs` | int | 100 | 训练轮数，必须大于 0 |
| `batch_size` | int | 16 | 批大小；`-1` 表示 Ultralytics 自动 batch |
| `image_size` | int | 640 | 输入尺寸 |
| `learning_rate` | float | 0.01 | 学习率 |
| `patience` | int | 50 | 早停耐心值 |
| `device` | string | `auto` | `auto` / `cpu` / `gpu` / `cuda:0` / `0,1` |
| `workers` | int | 8 | 数据加载进程数，允许 `-1` |
| `use_pretrained` | bool | true | 是否使用预训练权重 |
| `optimizer` | string | `AdamW` | 优化器 |
| `augmentation` | object | null | 数据增强参数；可通过选项接口获取可用字段 |
| `loss_weights` | object | null | 损失权重参数；可通过选项接口获取可用字段 |
| `additional_params` | object | null | 框架扩展参数，如 `framework_config` |

请求示例：

```json
{
  "project_id": 1,
  "architecture_id": 2,
  "name": "yolov8n-exp01",
  "parameters": {
    "epochs": 100,
    "batch_size": 16,
    "image_size": 640,
    "learning_rate": 0.01,
    "patience": 50,
    "device": "0",
    "workers": 8,
    "use_pretrained": true,
    "optimizer": "AdamW"
  }
}
```

响应：`201 Created`，返回 `TrainingRunOut`。

## 3. 训练参数选项

获取当前架构/引擎支持的数据增强参数：

```http
GET /api/v3/training-runs/augmentation-options?architecture_id=2
GET /api/v3/training-runs/augmentation-options?engine=ultralytics-yolo&task_type=detection
```

获取当前架构/引擎支持的损失权重参数：

```http
GET /api/v3/training-runs/loss-weight-options?architecture_id=2
GET /api/v3/training-runs/loss-weight-options?engine=ultralytics-yolo&task_type=detection
```

响应包含 `engine`、`task_type`、`defaults_policy` 和 `fields`。`fields` 内每项描述字段 key、展示名、类型、默认值、范围和适用任务。

## 4. 获取和更新训练任务

```http
GET /api/v3/training-runs/{run_id}
PATCH /api/v3/training-runs/{run_id}
```

更新请求体：

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 任务名称 |

## 5. 生命周期操作

### 5.1 加入队列

```http
POST /api/v3/training-runs/{run_id}/queue
```

将任务置为 `queued`，由对应 worker 轮询执行。

### 5.2 恢复训练

```http
POST /api/v3/training-runs/{run_id}/resume
```

只允许 `cancelled` 或 `failed` 任务恢复。若存在 `weights/last.pt`，会尝试恢复训练；否则按保存参数重新排队执行。

### 5.3 取消训练

```http
POST /api/v3/training-runs/{run_id}/cancel
Content-Type: application/json
```

请求体可直接传字符串作为取消原因：

```json
"用户手动取消"
```

### 5.4 删除训练任务

```http
DELETE /api/v3/training-runs/{run_id}?force=false
```

Query 参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `force` | bool | false | 是否级联处理关联模型版本和部署 |

非运行中任务删除时会清理对应训练目录。

## 6. 事件、指标和产物

### 6.1 事件

```http
GET /api/v3/training-runs/{run_id}/events?limit=200
```

`limit` 范围：1~5000。

### 6.2 Epoch 指标

```http
GET /api/v3/training-runs/{run_id}/metrics/epochs?limit=5000&source=auto
```

Query 参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `limit` | int | 5000 | 返回条数，1~100000 |
| `source` | string | `auto` | `auto` / `db` / `mlflow` |

响应示例：

```json
[
  {
    "metric_id": 1,
    "run_id": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40",
    "epoch": 0,
    "metrics": {
      "train/box_loss": 0.05,
      "metrics/mAP50(B)": 0.65
    },
    "created_at": "2026-06-13T02:10:00+00:00"
  }
]
```

### 6.3 产物列表

```http
GET /api/v3/training-runs/{run_id}/artifacts
```

返回训练权重、导出产物等 `TrainingRunArtifactOut` 列表。

## 7. 实时流

### 7.1 指标 WebSocket

```text
ws://<host>/api/v3/training-runs/{run_id}/metrics/stream?from_metric_id=0&from_event_id=0
```

消息类型：

| type | 说明 |
|------|------|
| `cursor` | 初始游标和服务端最新游标 |
| `status` | 状态、进度、epoch 和 worker 信息 |
| `metric` | 新增 epoch 指标 |
| `event` | 新增训练事件 |
| `done` | 任务达到终态 |
| `ping` | 心跳 |
| `error` | 错误信息 |

### 7.2 日志尾部

```http
GET /api/v3/training-runs/{run_id}/logs/tail?which=stdout&lines=200
```

Query 参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `which` | string | `stdout` | `stdout` 或 `stderr` |
| `lines` | int | 200 | 1~20000 |

### 7.3 日志 WebSocket

```text
ws://<host>/api/v3/training-runs/{run_id}/logs/stream?which=both&tail=500
```

Query 参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `which` | string | `stdout` / `stderr` / `both` / `all` |
| `tail` | int | 初始回溯行数，0~5000 |

消息类型：

| type | 说明 |
|------|------|
| `log` | 日志行，`data.mode` 为 `tail` 或 `append` |
| `done` | 训练任务结束 |
| `error` | 错误信息 |

## 8. 模型导出

创建导出：

```http
POST /api/v3/training-runs/{run_id}/export
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `format` | string | `pt` | `pt` 或 `onnx` |
| `weights` | string | `best` | `best` 或 `last` |
| `opset` | int | null | ONNX opset，9~20 |
| `dynamic` | bool | true | ONNX 动态轴 |
| `imgsz` | int | null | ONNX 输入尺寸，32~4096 |

响应：

```json
{
  "run_id": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40",
  "format": "onnx",
  "weights": "best",
  "download_url": "/api/v3/training-runs/8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40/export/download?format=onnx&weights=best",
  "artifact": {
    "artifact_id": 2,
    "run_id": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40",
    "kind": "export",
    "name": "best.onnx",
    "path": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40/weights/best.onnx",
    "size_bytes": 12345678,
    "sha256": null,
    "meta": null,
    "created_at": "2026-06-13T03:00:00+00:00"
  }
}
```

下载导出文件：

```http
GET /api/v3/training-runs/{run_id}/export/download?format=pt&weights=best
```

## 9. 训练报告

获取结构化训练报告：

```http
GET /api/v3/training-runs/{run_id}/report
```

下载可编辑 DOCX 训练报告：

```http
GET /api/v3/training-runs/{run_id}/report.docx
```

报告仅支持已完成训练任务；任务未完成时返回校验错误。

## 10. 训练对比

```http
POST /api/v3/training-runs/compare
Content-Type: application/json
```

请求体：

```json
{
  "run_ids": [
    "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40",
    "d68024e2-6df9-4c2d-9a02-b164fa38795f"
  ]
}
```

限制：`run_ids` 需包含 2~20 个训练任务。不同框架分组的任务会返回 `409 Conflict`，响应中包含 `framework_groups`。

响应字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `runs` | array | 每个训练任务的参数、指标、模型大小、推理耗时 |
| `parameter_diff` | object | 参数差异，按参数名分组 |

## 11. 推理耗时基准测量

```http
POST /api/v3/training-runs/benchmark-inference-time
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `run_ids` | string[] | 是 | - | 1~20 个训练任务 ID |
| `force` | bool | 否 | false | 是否忽略缓存重新测量 |

响应：

```json
{
  "items": [
    {
      "run_id": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40",
      "status": "cached",
      "inference_time_ms": 8.5,
      "engine": "ultralytics-yolo",
      "message": ""
    }
  ]
}
```

## 12. 元信息

获取元信息：

```http
GET /api/v3/training-runs/{run_id}/meta
```

更新元信息：

```http
PATCH /api/v3/training-runs/{run_id}/meta
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 说明 |
|------|------|------|
| `creator` | string | 创建者 |
| `group` | string | 分组名称；响应中序列化为 `group` |
| `tags` | any | 标签 |
| `notes` | string | 备注 |
| `extra` | object | 扩展信息 |

## 13. 数据模型

### TrainingRunOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `run_id` | string | 训练任务 ID |
| `project_id` | int | 项目 ID |
| `standard_dataset_id` | int | 标准数据集 ID |
| `architecture_id` | int | 架构 ID |
| `name` | string | 任务名称 |
| `status` | string | 任务状态 |
| `progress` | int | 0~100 |
| `current_epoch` | int | 当前 epoch |
| `total_epochs` | int? | 总 epoch |
| `queued_at` | datetime? | 入队时间 |
| `claimed_at` | datetime? | 被 worker 领取时间 |
| `worker_id` | string? | worker ID |
| `pid` | int? | 子进程 PID |
| `heartbeat_at` | datetime? | 最后心跳时间 |
| `cancel_requested_at` | datetime? | 取消请求时间 |
| `cancel_reason` | string? | 取消原因 |
| `delete_requested_at` | datetime? | 删除请求时间 |
| `hidden` | bool | 是否隐藏 |
| `run_dir` | string? | 运行目录名 |
| `started_at` | datetime? | 开始时间 |
| `finished_at` | datetime? | 结束时间 |
| `error_message` | string? | 错误信息 |
| `parameters` | object? | 训练参数 |
| `result` | object? | 训练结果、权重、指标摘要 |
| `meta` | object? | 元信息 |
| `created_at` | datetime | 创建时间 |
| `updated_at` | datetime | 更新时间 |
