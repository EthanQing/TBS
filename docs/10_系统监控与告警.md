# 系统监控与告警 API

> **系统监控前缀：** `/api/v3/system-metrics`
> **告警管理前缀：** `/api/v3/alarms`

系统监控接口返回后端、训练 worker、推理 worker 等节点的 CPU、内存、GPU 使用情况。告警接口基于训练任务规则生成活跃告警和历史告警。

---

## 一、系统监控

### 1. 获取节点实时摘要

```http
GET /api/v3/system-metrics/summary?node_id=backend&node_type=backend
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `node_id` | string | `backend` | 节点 ID，如 `backend` / `worker-yolo` |
| `node_type` | string | `backend` | 节点类型：`backend` / `worker` / `inference-worker` / `unknown` |

响应示例：

```json
{
  "timestamp": "2026-06-13T10:00:00+08:00",
  "node_id": "backend",
  "node_type": "backend",
  "cpu_percent": 35.2,
  "memory_percent": 44.5,
  "memory_used_mb": 29184.0,
  "memory_total_mb": 65536.0,
  "gpu_available": true,
  "gpu_count": 1,
  "gpu_percent": 80.0,
  "gpu_used_mb": 18000.0,
  "gpu_total_mb": 24576.0,
  "gpus": [
    {
      "gpu_index": 0,
      "name": "NVIDIA RTX 4090",
      "uuid": "GPU-xxxx",
      "utilization_percent": 80.0,
      "memory_used_mb": 18000.0,
      "memory_total_mb": 24576.0,
      "memory_percent": 73.2

  ]
}
```

### 2. 获取节点历史曲线

```http
GET /api/v3/system-metrics/history?minutes=10&node=backend&node_type=backend&step_seconds=5
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `minutes` | int | `10` | 历史窗口分钟数，范围 `1` 到 `1440` |
| `node` | string | `backend` | 节点 ID |
| `node_type` | string | `backend` | 节点类型 |
| `step_seconds` | int | `5` | 降采样步长，范围 `1` 到 `300` |

响应示例：

```json
{
  "node_id": "backend",
  "node_type": "backend",
  "window_seconds": 600,
  "step_seconds": 5,
  "points": [
    {
      "timestamp": "2026-06-13T09:59:55+08:00",
      "cpu_percent": 35.2,
      "memory_percent": 44.5,
      "memory_used_mb": 29184.0,
      "memory_total_mb": 65536.0,
      "gpu_available": true,
      "gpu_count": 1,
      "gpu_percent": 80.0,
      "gpu_used_mb": 18000.0,
      "gpu_total_mb": 24576.0,
      "gpus": []
    }
  ]
}
```

## 二、告警管理

### 1. 获取告警规则类型

```http
GET /api/v3/alarms/rule-types
```

当前支持的规则类型：

| rule_type | 说明 |
|-----------|------|
| `training_run_failed` | 训练任务失败 |
| `training_run_stale` | 训练任务长时间无进展 |

响应字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `rule_type` | string | 规则类型 |
| `name` | string | 展示名称 |
| `description` | string | 说明 |
| `default_severity` | string | 默认严重级别 |
| `default_enabled` | bool | 默认是否启用 |
| `default_cooldown_seconds` | int | 默认冷却时间 |
| `config_schema` | object | 规则配置 schema |

---

### 2. 规则管理

#### 2.1 获取规则列表

```http
GET /api/v3/alarms/rules?page=1&page_size=50&enabled=true
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `page` | int | `1` | 页码 |
| `page_size` | int | `50` | 每页数量，最大 `500` |
| `enabled` | bool? | `null` | 按启用状态过滤 |

响应为分页对象：

```json
{
  "items": [],
  "meta": {
    "page": 1,
    "page_size": 50,
    "total": 0
  }
}
```

#### 2.2 创建规则

```http
POST /api/v3/alarms/rules
Content-Type: application/json
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `rule_type` | string | 是 | - | `training_run_failed` / `training_run_stale` |
| `name` | string | 是 | - | 规则名称 |
| `description` | string? | 否 | `null` | 规则说明 |
| `severity` | string | 否 | `high` | `critical` / `high` / `medium` / `low` |
| `enabled` | bool | 否 | `true` | 是否启用 |
| `cooldown_seconds` | int | 否 | `300` | 冷却时间，范围 `0` 到 `86400` |
| `config` | object | 否 | `{}` | 规则配置 |

#### 2.3 更新规则

```http
PATCH /api/v3/alarms/rules/{rule_id}
Content-Type: application/json
```

请求体可包含创建规则中的可更新字段：`name`、`description`、`severity`、`enabled`、`cooldown_seconds`、`config`。

#### 2.4 删除规则

```http
DELETE /api/v3/alarms/rules/{rule_id}
```

响应示例：

```json
{
  "ok": true,
  "message": "Alarm rule deleted"
}
```

---

### 3. 手动评估告警

```http
POST /api/v3/alarms/evaluate
Content-Type: application/json
```

请求体可为空；为空时评估所有相关训练任务。

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `run_ids` | string[] | `[]` | 指定训练任务 ID 列表 |

响应示例：

```json
{
  "evaluated_runs": 3,
  "triggered_new": 1,
  "touched_active": 0,
  "resolved": 0,
  "active_total": 1,
  "timestamp": "2026-06-13T10:00:00+08:00"
}
```

---

### 4. 活跃告警

```http
GET /api/v3/alarms/active?page=1&page_size=50&severity=high&rule_type=training_run_failed&source_id=run-001
```

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `page` | int | `1` | 页码 |
| `page_size` | int | `50` | 每页数量，最大 `500` |
| `severity` | string? | `null` | 严重级别 |
| `rule_type` | string? | `null` | 规则类型 |
| `source_id` | string? | `null` | 来源 ID，如训练任务 ID |

---

### 5. 确认告警

```http
POST /api/v3/alarms/active/{alert_id}/ack
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 说明 |
|------|------|------|
| `acked_by` | string? | 确认人 |

---

### 6. 告警历史

```http
GET /api/v3/alarms/history?page=1&page_size=50&severity=high&rule_type=training_run_failed&source_id=run-001
```

参数同活跃告警列表，返回状态为 `resolved` 的告警分页。

---

### 7. 告警汇总

```http
GET /api/v3/alarms/summary
```

响应示例：

```json
{
  "active_total": 3,
  "by_severity": {
    "critical": 0,
    "high": 2,
    "medium": 1,
    "low": 0
  }
}
```

## 数据模型

### SystemMetricOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `timestamp` | datetime | 采集时间 |
| `node_id` | string | 节点 ID |
| `node_type` | string | 节点类型 |
| `cpu_percent` | float? | CPU 使用率 |
| `memory_percent` | float? | 内存使用率 |
| `memory_used_mb` | float? | 已用内存 MB |
| `memory_total_mb` | float? | 总内存 MB |
| `gpu_available` | bool | 是否可用 GPU |
| `gpu_count` | int | GPU 数量 |
| `gpu_percent` | float? | 聚合 GPU 使用率 |
| `gpu_used_mb` | float? | 聚合 GPU 显存使用量 |
| `gpu_total_mb` | float? | 聚合 GPU 显存总量 |
| `gpus` | object[] | 单卡指标 |

### GpuDeviceMetricOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `gpu_index` | int | GPU 序号 |
| `name` | string | GPU 名称 |
| `uuid` | string? | GPU UUID |
| `utilization_percent` | float? | GPU 使用率 |
| `memory_used_mb` | float? | 已用显存 MB |
| `memory_total_mb` | float? | 总显存 MB |
| `memory_percent` | float? | 显存使用率 |

### AlarmRuleOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `rule_id` | int | 规则 ID |
| `rule_type` | string | 规则类型 |
| `name` | string | 规则名称 |
| `description` | string? | 规则说明 |
| `severity` | string | `critical` / `high` / `medium` / `low` |
| `enabled` | bool | 是否启用 |
| `cooldown_seconds` | int | 冷却时间 |
| `config` | object | 规则配置 |
| `created_at` | datetime? | 创建时间 |
| `updated_at` | datetime? | 更新时间 |

### AlarmAlertOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `alert_id` | int | 告警 ID |
| `rule_id` | int? | 规则 ID |
| `rule_type` | string | 规则类型 |
| `severity` | string | 严重级别 |
| `status` | string | `active` / `resolved` |
| `title` | string | 标题 |
| `message` | string? | 告警消息 |
| `source_type` | string | 当前为 `training_run` |
| `source_id` | string | 来源 ID |
| `trigger_count` | int | 触发次数 |
| `first_triggered_at` | datetime | 首次触发时间 |
| `last_triggered_at` | datetime | 最近触发时间 |
| `resolved_at` | datetime? | 解决时间 |
| `acked_at` | datetime? | 确认时间 |
| `acked_by` | string? | 确认人 |
| `payload` | object | 附加信息 |
| `created_at` | datetime? | 创建时间 |
| `updated_at` | datetime? | 更新时间 |
