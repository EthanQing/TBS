# 在线服务 API (Serving)

> **路由前缀：** `/api/v3/serving`
> **标签：** `serving`

在线服务模块提供部署后的生产推理入口。调用方需要先执行部署任务并获取 API Key，再通过 Serving API 对已激活部署发起推理。

---

## 鉴权方式

除健康检查显式传 `auth_required=false` 的场景外，在线服务请求需要携带部署 API Key。支持两种请求头：

```http
X-Deployment-Key: sk-xxxxxxxxxxxx
```

或：

```http
Authorization: Bearer sk-xxxxxxxxxxxx
```

API Key 由部署执行接口生成：

```http
POST /api/v3/deployments/{deployment_id}/execute
```

`issued_api_key` 只在执行或重试部署时返回一次；后续普通部署详情只返回 `api_key_hint`。

---

## 1. 部署健康检查

```http
GET /api/v3/serving/deployments/{deployment_id}/health?auth_required=true
```

检查部署是否存在、是否为激活状态，以及是否已配置 API Key。

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `deployment_id` | int | - | 部署 ID |
| `auth_required` | bool | `true` | 是否校验 API Key |

响应示例：

```json
{
  "ok": true,
  "deployment_id": 1,
  "model_version_id": 10,
  "endpoint_url": "http://localhost:8080",
  "status": "active"
}
```

常见错误：

| 状态码 | 说明 |
|--------|------|
| 401 | API Key 缺失或无效 |
| 404 | 部署不存在 |
| 409 | 部署未激活，或没有配置 API Key |

## 2. 在线推理

```http
POST /api/v3/serving/deployments/{deployment_id}/infer
```

部署必须满足 `is_active=true` 且 `status=active`。请求必须提供且只能提供一个输入来源：上传文件或图片 URL。

### 2.1 JSON 请求

```http
Content-Type: application/json
X-Deployment-Key: sk-xxxxxxxxxxxx
```

JSON 方式只能使用 `image_url`：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `image_url` | string | 是 | - | 图片 HTTP(S) URL |
| `conf` | float | 否 | `0.5` | 置信度阈值 |
| `iou` | float | 否 | `0.45` | NMS IOU 阈值 |
| `show_labels` | bool | 否 | `true` | 写入输入元信息 |
| `show_confidence` | bool | 否 | `true` | 写入输入元信息 |

```json
{
  "image_url": "https://example.com/photo.jpg",
  "conf": 0.5,
  "iou": 0.45,
  "show_labels": true,
  "show_confidence": true
}
```

### 2.2 multipart/form-data 请求

```http
Content-Type: multipart/form-data
X-Deployment-Key: sk-xxxxxxxxxxxx
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `file` | File | 二选一 | - | 图片文件 |
| `image_url` | string | 二选一 | - | 图片 HTTP(S) URL |
| `conf` | float | 否 | `0.5` | 置信度阈值 |
| `iou` | float | 否 | `0.45` | NMS IOU 阈值 |
| `show_labels` | string | 否 | `true` | `true`/`false`、`1`/`0`、`yes`/`no` |
| `show_confidence` | string | 否 | `true` | `true`/`false`、`1`/`0`、`yes`/`no` |

`file` 和 `image_url` 必须恰好提供一个；同时提供或都不提供会返回校验错误。

### 响应示例

```json
{
  "deployment_id": 1,
  "model_version_id": 10,
  "engine": "ultralytics-yolo",
  "family": "yolo",
  "variant": "yolov8n",
  "run_id": "train-run-001",
  "input_path": "serving_uploads/50f7a7.jpg",
  "input_meta": {
    "show_labels": true,
    "show_confidence": true
  },
  "inference_time_ms": 12.5,
  "names": {
    "0": "person",
    "1": "car"
  },
  "predictions": [
    {
      "class_id": 0,
      "class_name": "person",
      "confidence": 0.92,
      "bbox": [100, 200, 300, 500]
    }
  ],
  "raw_output": {
    "predictions": [],
    "names": {}
  }
}
```

## 3. 创建 Serving Job（当前未启用）

```http
POST /api/v3/serving/deployments/{deployment_id}/jobs
Content-Type: application/json
```

该接口保留批量/视频 Serving Job 的接口形态，但当前 V3 未启用异步 Serving Job，固定返回 `enabled=false`。

请求体：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `mode` | string | 是 | `batch` 或 `video` |
| `deployment_id` | int | 是 | 部署 ID |

响应示例：

```json
{
  "enabled": false,
  "status": "not_enabled",
  "message": "mode not enabled in V3",
  "mode": "batch",
  "job_id": null
}
```

## 调用示例

### cURL

```bash
curl -X POST "http://localhost:8000/api/v3/serving/deployments/1/infer" \
  -H "X-Deployment-Key: sk-xxxxxxxxxxxx" \
  -H "Content-Type: application/json" \
  -d '{"image_url":"https://example.com/test.jpg","conf":0.5}'

curl -X POST "http://localhost:8000/api/v3/serving/deployments/1/infer" \
  -H "X-Deployment-Key: sk-xxxxxxxxxxxx" \
  -F "file=@/path/to/image.jpg" \
  -F "conf=0.5"
```

### Python

```python
import requests

api_url = "http://localhost:8000/api/v3/serving/deployments/1/infer"
api_key = "sk-xxxxxxxxxxxx"

response = requests.post(
    api_url,
    headers={
        "X-Deployment-Key": api_key,
        "Content-Type": "application/json",
    },
    json={
        "image_url": "https://example.com/test.jpg",
        "conf": 0.5,
        "iou": 0.45,
    },
)
result = response.json()
print(result["predictions"])
```

## 数据模型

### ServingInferResponse

| 字段 | 类型 | 说明 |
|------|------|------|
| `deployment_id` | int | 部署 ID |
| `model_version_id` | int | 模型版本 ID |
| `engine` | string? | 推理引擎 |
| `family` | string? | 模型族 |
| `variant` | string? | 模型变体 |
| `run_id` | string? | 来源训练任务 ID |
| `input_path` | string? | 上传文件保存后的临时 token，URL 输入时可能为空 |
| `input_meta` | object? | 输入元信息 |
| `inference_time_ms` | float? | 推理耗时，单位毫秒 |
| `names` | object? | 类名映射 |
| `predictions` | object[] | 推理结果 |
| `raw_output` | object? | 推理服务原始输出 |

### ServingJobOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `enabled` | bool | 当前是否启用异步 Serving Job |
| `status` | string | 当前固定为 `not_enabled` |
| `message` | string | 说明 |
| `mode` | string? | 请求的 Job 模式 |
| `job_id` | string? | Job ID |
