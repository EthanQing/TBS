# 模型版本 API (Model Versions)

> 路由前缀：`/api/v3/model-versions`
> 标签：`model-versions`

模型版本是从已完成训练任务注册出来的模型资产，可用于部署、在线服务和推理任务。合格模型的人工确认见 [12_合格模型.md](12_合格模型.md)。

## 1. 获取模型版本列表

```http
GET /api/v3/model-versions
```

Query 参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `page` | int | 否 | 1 | 页码 |
| `page_size` | int | 否 | 50 | 每页条数，1~500 |
| `project_id` | int | 否 | - | 按项目过滤 |
| `run_id` | string | 否 | - | 按训练任务 ID 过滤 |
| `stage` | string | 否 | - | `development` / `testing` / `production` / `deprecated` |

响应示例：

```json
{
  "items": [
    {
      "model_version_id": 1,
      "project_id": 1,
      "run_id": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40",
      "version": "v1.0.0",
      "stage": "production",
      "description": "车辆检测模型首次发布",
      "metrics": {
        "metrics/mAP50(B)": 0.85
      },
      "weights_path": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40/weights/best.pt",
      "created_at": "2026-06-13T02:30:00+00:00",
      "updated_at": "2026-06-13T02:30:00+00:00"
    }
  ],
  "meta": {
    "page": 1,
    "page_size": 50,
    "total": 1
  }
}
```

## 2. 注册模型版本

```http
POST /api/v3/model-versions
Content-Type: application/json
```

从已完成训练任务注册模型版本。

请求体：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `run_id` | string | 是 | - | 来源训练任务 ID |
| `version` | string | 是 | - | 版本号，1~50 字符，建议语义化 |
| `stage` | string | 否 | `development` | 模型阶段 |
| `description` | string | 否 | - | 说明 |

请求示例：

```json
{
  "run_id": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40",
  "version": "v1.0.0",
  "stage": "production",
  "description": "车辆检测模型首次发布"
}
```

响应：`201 Created`，返回 `ModelVersionOut`。

## 3. 获取模型版本详情

```http
GET /api/v3/model-versions/{model_version_id}
```

路径参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `model_version_id` | int | 模型版本 ID |

## 4. 更新模型版本

```http
PATCH /api/v3/model-versions/{model_version_id}
Content-Type: application/json
```

请求体可传字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `version` | string | 版本号，1~50 字符 |
| `stage` | string | `development` / `testing` / `production` / `deprecated` |
| `description` | string | 说明 |

## 5. 数据模型

### ModelVersionOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `model_version_id` | int | 模型版本 ID |
| `project_id` | int | 项目 ID |
| `run_id` | string | 来源训练任务 ID |
| `version` | string | 版本号 |
| `stage` | string | 阶段 |
| `description` | string? | 说明 |
| `metrics` | object? | 模型指标，通常来自训练结果 |
| `weights_path` | string? | 权重相对路径 |
| `created_at` | datetime | 创建时间 |
| `updated_at` | datetime | 更新时间 |

## 6. 使用说明

- 只有训练任务完成并存在可用权重时才适合注册模型版本。
- `weights_path` 是后端训练目录下的相对路径，部署和推理服务会通过后端路径解析读取。
- 同一个训练任务可以注册多个版本标签，但业务上建议同一阶段只保留清晰可追踪的版本。
