# 模型转换 API (Model Conversions)

> **路由前缀：** `/api/v3/model-conversions`
> **标签：** `model-conversions`

模型转换模块用于将 YOLO PyTorch 权重文件（`.pt` / `.pth`）转换为 ONNX，并尽力执行性能基准测试。转换任务由 YOLO worker 轮询 `temp/model_conversions` 状态文件执行。

---

## 1. 创建模型转换任务

```http
POST /api/v3/model-conversions
Content-Type: multipart/form-data
```

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `file` | File | 是 | - | PyTorch 权重文件，支持 `.pt` / `.pth` |
| `source_format` | string | 否 | `pt` | 源格式：`pt` / `pth` |
| `target_format` | string | 否 | `onnx` | 当前只支持 `onnx` |
| `opset` | int? | 否 | `null` | ONNX opset 版本 |
| `dynamic` | bool | 否 | `true` | 是否使用动态轴 |

当前只支持 YOLO/Ultralytics 生态的 PT/PTH -> ONNX 转换。

响应示例：

```json
{
  "job_id": "abc123def456",
  "status": "queued",
  "progress": 0,
  "logs": [
    "已接收文件: model.pt",
    "source_format=pt target_format=onnx",
    "已加入 YOLO worker 转换队列"
  ],
  "output_url": null,
  "output_filename": null,
  "performance": null,
  "error_message": null,
  "created_at": "2026-06-13T10:00:00+08:00",
  "updated_at": "2026-06-13T10:00:00+08:00"
}
```

## 2. 查询转换任务

```http
GET /api/v3/model-conversions/{job_id}
```

响应模型为 `ModelConversionOut`。


## 3. 下载转换结果

```http
GET /api/v3/model-conversions/{job_id}/download
```

任务必须为 `completed`。接口返回转换后的模型文件流：

```http
Content-Type: application/octet-stream
```

如果任务未完成、输出文件不存在或输出路径不安全，会返回校验错误。

---

## 转换流程

1. API 接收上传的 PT/PTH 文件，保存到任务目录。
2. API 写入任务状态文件，状态为 `queued`。
3. YOLO worker 轮询并执行模型加载、ONNX 导出和性能测试。
4. worker 持续更新 `progress`、`logs`、`output_url`、`performance` 和 `error_message`。
5. 客户端通过查询接口轮询状态，完成后调用下载接口。

---

## 数据模型

### ModelConversionOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `job_id` | string | 任务 ID |
| `status` | string | 状态：`queued` / `running` / `completed` / `failed` |
| `progress` | int | 进度百分比 |
| `logs` | string[] | 日志行 |
| `output_url` | string? | ONNX 文件静态 URL |
| `output_filename` | string? | 输出文件名 |
| `performance` | object? | 性能对比数据 |
| `error_message` | string? | 错误信息 |
| `created_at` | datetime? | 创建时间 |
| `updated_at` | datetime? | 更新时间 |

### ModelConversionPerfOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `device` | string? | 测试设备，如 `cuda` / `cpu` |
| `onnx_provider` | string? | ONNX Runtime Provider |
| `imgsz` | int? | 测试输入尺寸 |
| `pt` | object? | 原始 PT/PTH 性能 |
| `onnx` | object? | ONNX 性能 |

### ModelConversionPerfItem

| 字段 | 类型 | 说明 |
|------|------|------|
| `latency_ms` | float? | 单次推理延迟，单位毫秒 |
| `throughput_img_s` | float? | 吞吐量，张/秒 |
| `size_mb` | float? | 模型文件大小，单位 MB |

性能测试是 best-effort，不影响模型转换结果。测试失败时任务仍可能成功，并只返回可用的文件大小或空性能字段。
