# 推理服务 API (Inference)

> 路由前缀：`/api/v3/inference-runs`、`/api/v3/inference-jobs`
> 标签：`inference`、`inference-jobs`

推理模块分为两类：

- 同步推理：`/api/v3/inference-runs`，适合单图、少量批量或快速视频抽帧处理。
- 异步推理任务：`/api/v3/inference-jobs`，适合批量/视频任务、进度跟踪和 WebSocket 实时结果。

部署后对外在线推理接口见 [07_在线服务.md](07_在线服务.md)。

## 1. 同步推理

### 1.1 上传推理文件

```http
POST /api/v3/inference-runs/upload
Content-Type: multipart/form-data
```

表单字段：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `file` | File | 是 | 图片或视频文件 |

响应：

```json
{
  "token": "inference_uploads/12ab34cd.jpg",
  "path": "/static/temp/inference_uploads/12ab34cd.jpg"
}
```

`token` 可作为后续推理接口的 `input_path`、`input_tokens` 或 `video_token`。

### 1.2 单次推理

```http
POST /api/v3/inference-runs
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `model_version_id` | int | 是 | - | 模型版本 ID |
| `deployment_id` | int | 否 | - | 关联部署 ID |
| `input_path` | string | 二选一 | - | 上传 token、`/static/temp/...` URL 或后端可访问路径 |
| `image_url` | string | 二选一 | - | HTTP(S) 图片 URL |
| `conf` | float | 否 | 0.5 | 置信度阈值，0~1 |
| `iou` | float | 否 | 0.45 | IoU 阈值，0~1 |
| `input_meta` | object | 否 | null | 输入附加信息 |

请求示例：

```json
{
  "model_version_id": 10,
  "input_path": "inference_uploads/12ab34cd.jpg",
  "conf": 0.5,
  "iou": 0.45
}
```

响应：

```json
{
  "inference_id": 1,
  "model_version_id": 10,
  "deployment_id": null,
  "input_path": "inference_uploads/12ab34cd.jpg",
  "input_meta": null,
  "output": {
    "predictions": [
      {
        "class_id": 0,
        "class_name": "car",
        "confidence": 0.92,
        "bbox": [100, 200, 300, 500]
      }
    ],
    "names": {
      "0": "car"
    }
  },
  "error_message": null,
  "created_at": "2026-06-13T03:40:00+00:00"
}
```

### 1.3 批量同步推理

```http
POST /api/v3/inference-runs/batch
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `model_version_id` | int | 是 | - | 模型版本 ID |
| `input_tokens` | string[] | 是 | - | 上传 token 列表 |
| `conf` | float | 否 | 0.5 | 置信度阈值 |
| `iou` | float | 否 | 0.45 | IoU 阈值 |

响应：

```json
{
  "results": [
    {
      "filename": "12ab34cd.jpg",
      "token": "inference_uploads/12ab34cd.jpg",
      "output": {
        "predictions": [],
        "names": {}
      },
      "error_message": null,
      "inference_time_ms": 15.2
    }
  ],
  "total": 1,
  "success_count": 1,
  "total_time_ms": 20.1
}
```

### 1.4 视频同步推理

```http
POST /api/v3/inference-runs/video
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `model_version_id` | int | 是 | - | 模型版本 ID |
| `video_token` | string | 是 | - | 上传视频 token |
| `conf` | float | 否 | 0.5 | 置信度阈值 |
| `iou` | float | 否 | 0.45 | IoU 阈值 |
| `frame_interval` | int | 否 | 1 | 每隔 N 帧推理一次 |

响应字段包括 `results`、`total_frames`、`processed_frames`、`total_time_ms`。

## 2. 异步推理任务

### 2.1 获取可推理模型

```http
GET /api/v3/inference-jobs/models?project_id=1
```

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `project_id` | int | 否 | 按项目过滤 |

响应项来源可能是已注册模型版本，也可能是已完成训练任务：

```json
[
  {
    "source": "model_version",
    "model_version_id": 10,
    "run_id": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40",
    "project_id": 1,
    "architecture_id": 2,
    "engine": "ultralytics-yolo",
    "family": "yolo",
    "variant": "yolov8n",
    "version": "v1.0.0",
    "label": "yolov8n v1.0.0",
    "weights_path": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40/weights/best.pt",
    "config_path": null,
    "inferable": true,
    "infer_reason": null,
    "created_at": "2026-06-13T03:30:00+00:00"
  }
]
```

### 2.2 创建推理任务

```http
POST /api/v3/inference-jobs
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `mode` | string | 否 | `image` | `image` / `batch` / `video` |
| `model_version_id` | int | 二选一 | - | 模型版本 ID |
| `run_id` | string | 二选一 | - | 已完成训练任务 ID |
| `input_tokens` | string[] | image/batch 必填 | [] | 上传图片 token 列表 |
| `video_token` | string | video 必填 | - | 上传视频 token |
| `conf` | float | 否 | 0.5 | 置信度阈值 |
| `iou` | float | 否 | 0.45 | IoU 阈值 |
| `show_labels` | bool | 否 | true | 渲染结果图时显示标签 |
| `show_confidence` | bool | 否 | true | 渲染结果图时显示置信度 |

请求示例：

```json
{
  "mode": "batch",
  "model_version_id": 10,
  "input_tokens": [
    "inference_uploads/12ab34cd.jpg",
    "inference_uploads/56ef78ab.jpg"
  ],
  "conf": 0.5,
  "iou": 0.45,
  "show_labels": true,
  "show_confidence": true
}
```

响应：`201 Created`，返回 `InferenceJobOut`。

### 2.3 获取推理任务详情

```http
GET /api/v3/inference-jobs/{job_id}?include_items=true
```

Query 参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `include_items` | bool | true | 是否包含结果项 |

### 2.4 取消推理任务

```http
POST /api/v3/inference-jobs/{job_id}/cancel
```

### 2.5 推理任务 WebSocket

```text
ws://<host>/api/v3/inference-jobs/{job_id}/stream?from_seq=0&from_result_id=0
```

消息类型：

| type | 说明 |
|------|------|
| `snapshot` | 初始任务快照 |
| `progress` | 进度、状态和阶段更新 |
| `item` | 单个图片结果项 |
| `done` | 任务达到终态 |
| `error` | 错误 |
| `ping` | 心跳 |

`progress` 示例：

```json
{
  "type": "progress",
  "data": {
    "job_id": "job-001",
    "status": "running",
    "phase": "inferring",
    "mode": "batch",
    "progress": 60,
    "processed": 30,
    "total": 50,
    "seq": 15,
    "last_result_id": 30
  }
}
```

## 3. 数据模型

### InferenceJobOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `job_id` | string | 任务 ID |
| `status` | string | `queued` / `running` / `completed` / `failed` / `cancelled` |
| `phase` | string? | `preparing` / `inferring` / `rendering` / `finalizing` / `done` / `failed` / `cancelled` |
| `mode` | string | `image` / `batch` / `video` |
| `progress` | int | 0~100 |
| `processed` | int | 已处理数量 |
| `total` | int | 总数量 |
| `seq` | int | 进度序号 |
| `last_result_id` | int | 最新结果 ID |
| `model_version_id` | int? | 模型版本 ID |
| `run_id` | string? | 训练任务 ID |
| `engine` | string? | 推理引擎 |
| `family` | string? | 模型族 |
| `variant` | string? | 模型变体 |
| `result` | object? | 结果汇总，包含 `items` 或 `video` |
| `error_message` | string? | 错误信息 |
| `cancel_requested` | bool | 是否请求取消 |
| `created_at` | datetime? | 创建时间 |
| `updated_at` | datetime? | 更新时间 |

### InferenceJobItemResult

| 字段 | 类型 | 说明 |
|------|------|------|
| `result_id` | int | 结果 ID |
| `filename` | string | 文件名 |
| `token` | string? | 输入 token |
| `status` | string | `success` 或 `failed` |
| `detections` | int | 检测目标数 |
| `inference_time_ms` | float? | 推理耗时 |
| `source_url` | string? | 原图 URL |
| `output_url` | string? | 渲染结果 URL |
| `output` | object? | 原始推理输出 |
| `error_message` | string? | 错误信息 |
