# 数据集增强 API

> **路由前缀：** `/api/v3/standard-datasets/{standard_dataset_id}/augmentations`
> **标签：** `dataset-augmentations`

当前后端没有独立的 `/dataset-conversions` 路由。违规/非法原始数据发布为标准数据集的流程请查看 [02_数据集管理.md](02_数据集管理.md) 中的 `/api/v3/illegal-datasets/{illegal_dataset_id}/publish-jobs`。本文档只描述标准数据集增强接口。

---

## 1. 预览增强效果

```http
POST /api/v3/standard-datasets/{standard_dataset_id}/augmentations/preview
Content-Type: application/json
```

预览接口只估算当前配置会生成多少输出，不创建后台任务，也不修改数据集。

请求体同 `DatasetAugmentationConfig`。

响应示例：

```json
{
  "total_images": 1200,
  "with_labels": 1180,
  "estimated_generated_outputs": 3600,
  "estimated_total_outputs": 4800,
  "per_transform": {
    "slice": 2400,
    "rotate": 1200
  },
  "note": null
}
```

## 2. 创建增强任务

```http
POST /api/v3/standard-datasets/{standard_dataset_id}/augmentations
Content-Type: application/json
```

创建后台增强任务。任务状态通过查询接口或 WebSocket 实时流获取。

请求示例：

```json
{
  "version_id": 3,
  "include_original": true,
  "max_outputs_per_image": 200,
  "slice": {
    "enabled": true,
    "scales": [640, 960],
    "overlap": 0.2,
    "min_area_ratio": 0.3,
    "min_visibility": 0.15,
    "min_pixel_size": 4
  },
  "rotate": {
    "enabled": true,
    "angles": [-10, 10],
    "border_value": 114
  },
  "translate": {
    "enabled": false,
    "offsets": [],
    "border_value": 114
  }
}
```

响应示例：

```json
{
  "job_id": "aug-001",
  "standard_dataset_id": 2000001,
  "status": "queued",
  "phase": "preparing",
  "progress": 0,
  "processed": 0,
  "total": 0,
  "seq": 0,
  "last_result_id": 0,
  "config": {
    "version_id": 3,
    "include_original": true,
    "max_outputs_per_image": 200,
    "slice": {
      "enabled": true,
      "scales": [640],
      "overlap": 0.2,
      "min_area_ratio": 0.3,
      "min_visibility": 0.15,
      "min_pixel_size": 4
    },
    "rotate": {
      "enabled": false,
      "angles": [],
      "border_value": 114
    },
    "translate": {
      "enabled": false,
      "offsets": [],
      "border_value": 114
    }
  },
  "result": null,
  "cancel_requested": false,
  "error_message": null,
  "created_at": "2026-06-13T10:00:00+08:00",
  "updated_at": "2026-06-13T10:00:00+08:00"
}
```

## 3. 查询增强任务

```http
GET /api/v3/standard-datasets/{standard_dataset_id}/augmentations/{job_id}
```

响应模型为 `DatasetAugmentationJobOut`。

任务状态：

| 状态 | 说明 |
|------|------|
| `queued` | 已创建，等待执行 |
| `running` | 正在执行 |
| `completed` | 已完成，可发布 |
| `failed` | 执行失败，查看 `error_message` |
| `cancelled` | 已取消 |

任务阶段：

| 阶段 | 说明 |
|------|------|
| `preparing` | 准备任务 |
| `scanning` | 扫描数据集 |
| `augmenting` | 执行增强 |
| `finalizing` | 收尾写入结果 |
| `done` | 完成 |
| `failed` | 失败 |
| `cancelled` | 已取消 |

---

## 4. 取消增强任务

```http
POST /api/v3/standard-datasets/{standard_dataset_id}/augmentations/{job_id}/cancel
```

响应示例：

```json
{
  "job_id": "aug-001",
  "status": "cancelled",
  "cancel_requested": true
}
```

## 5. 发布增强结果

```http
POST /api/v3/standard-datasets/{standard_dataset_id}/augmentations/{job_id}/publish
Content-Type: application/json
```

把增强任务结果发布为新的标准数据集。发布成功后响应会返回新标准数据集 ID。

请求体：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `activate` | bool | `false` | 是否激活为目标数据集当前版本 |
| `message` | string? | `null` | 版本说明 |
| `created_by` | string? | `null` | 操作人 |

请求示例：

```json
{
  "activate": true,
  "message": "切片和旋转增强版本",
  "created_by": "admin"
}
```

响应示例：

```json
{
  "standard_dataset_id": 2000123,
  "job_id": "aug-001",
  "source_standard_dataset_id": 2000001
}
```

## 6. 增强进度实时流

```text
ws://<host>/api/v3/standard-datasets/{standard_dataset_id}/augmentations/{job_id}/stream?from_seq=0&from_result_id=0
```

| 查询参数 | 类型 | 说明 |
|----------|------|------|
| `from_seq` | int | 从指定任务状态序号之后继续接收；默认 `0` |
| `from_result_id` | int | 从指定结果 ID 之后继续接收；默认 `0` |

消息类型：

| `type` | 说明 |
|--------|------|
| `snapshot` | 连接后的任务快照 |
| `progress` | 任务进度更新 |
| `item` | 单张图片增强结果 |
| `done` | 任务结束 |
| `error` | 错误 |
| `ping` | 心跳 |

`progress` 消息示例：

```json
{
  "type": "progress",
  "data": {
    "job_id": "aug-001",
    "standard_dataset_id": 2000001,
    "status": "running",
    "phase": "augmenting",
    "progress": 60,
    "processed": 600,
    "total": 1000,
    "seq": 30,
    "last_result_id": 600,
    "error_message": null,
    "result": null
  }
}
```

## 数据模型

### DatasetAugmentationConfig

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `version_id` | int? | `null` | 指定标准数据集版本；为空时使用当前版本 |
| `include_original` | bool | `true` | 输出是否包含原图 |
| `max_outputs_per_image` | int | `200` | 单张原图最多输出数量，范围 `1` 到 `5000` |
| `slice` | object | 见下方 | 切片配置 |
| `rotate` | object | 见下方 | 旋转配置 |
| `translate` | object | 见下方 | 平移配置 |

### slice

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enabled` | bool | `true` | 是否启用切片 |
| `scales` | int[] | `[640]` | 切片尺度，小于 32 的值会被过滤 |
| `overlap` | float | `0.2` | 重叠比例，范围 `[0, 1)` |
| `min_area_ratio` | float | `0.3` | 最小保留面积比例 |
| `min_visibility` | float | `0.15` | 最小可见比例 |
| `min_pixel_size` | int | `4` | 最小像素尺寸 |

### rotate

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enabled` | bool | `false` | 是否启用旋转 |
| `angles` | float[] | `[]` | 旋转角度列表，会去重排序 |
| `border_value` | int | `114` | 边界填充值，范围 `0` 到 `255` |

### translate

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `enabled` | bool | `false` | 是否启用平移 |
| `offsets` | object[] | `[]` | 平移偏移，元素包含 `dx`、`dy`，范围 `[-1, 1]` |
| `border_value` | int | `114` | 边界填充值，范围 `0` 到 `255` |

### DatasetAugmentationJobOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `job_id` | string | 任务 ID |
| `standard_dataset_id` | int | 标准数据集 ID |
| `status` | string | 任务状态 |
| `phase` | string? | 当前阶段 |
| `progress` | int | 进度百分比 |
| `processed` | int | 已处理数量 |
| `total` | int | 总数量 |
| `seq` | int | 状态序号 |
| `last_result_id` | int | 最新结果 ID |
| `config` | object? | 增强配置 |
| `result` | object? | 任务结果 |
| `cancel_requested` | bool | 是否请求取消 |
| `error_message` | string? | 错误信息 |
| `created_at` | datetime? | 创建时间 |
| `updated_at` | datetime? | 更新时间 |

### DatasetAugmentationResult

| 字段 | 类型 | 说明 |
|------|------|------|
| `output_url` | string? | 输出文件 URL |
| `output_file_count` | int | 输出文件数 |
| `generated_images` | int | 生成图片数 |
| `generated_labels` | int | 生成标签数 |
| `published_standard_dataset_id` | int? | 发布后生成的标准数据集 ID |
