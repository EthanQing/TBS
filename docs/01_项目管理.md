# 项目管理 API (Projects)

> 路由前缀：`/api/v3/projects`
> 标签：`projects`

项目是训练任务的组织单元。每个项目绑定一个标准数据集（`standard_dataset_id`），并指定任务类型；训练任务创建时会继承项目绑定的数据集。

## 1. 获取项目列表

```http
GET /api/v3/projects
```

Query 参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `page` | int | 否 | 1 | 页码，最小值 1 |
| `page_size` | int | 否 | 50 | 每页条数，1~500 |
| `standard_dataset_id` | int | 否 | - | 按标准数据集 ID 过滤 |

响应示例：

```json
{
  "items": [
    {
      "project_id": 1,
      "name": "车辆检测项目",
      "description": "道路场景车辆检测",
      "standard_dataset_id": 2000001,
      "task_type": "detection",
      "created_by": "admin",
      "tags": {
        "priority": "high"
      },
      "is_active": true,
      "created_at": "2026-06-13T02:00:00+00:00",
      "updated_at": "2026-06-13T02:00:00+00:00"
    }
  ],
  "meta": {
    "page": 1,
    "page_size": 50,
    "total": 1
  }
}
```

## 2. 创建项目

```http
POST /api/v3/projects
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `name` | string | 是 | 项目名称，1~255 字符 |
| `standard_dataset_id` | int | 是 | 绑定的标准数据集 ID |
| `task_type` | string | 是 | `detection` / `segmentation` / `classification` |
| `description` | string | 否 | 项目说明 |
| `created_by` | string | 否 | 创建者 |
| `tags` | object | 否 | 自定义标签 |

请求示例：

```json
{
  "name": "车辆检测项目",
  "standard_dataset_id": 2000001,
  "task_type": "detection",
  "description": "道路场景车辆检测",
  "created_by": "admin"
}
```

响应：`201 Created`，返回 `ProjectOut`。

## 3. 获取项目详情

```http
GET /api/v3/projects/{project_id}
```

路径参数：

| 参数 | 类型 | 说明 |
|------|------|------|
| `project_id` | int | 项目 ID |

## 4. 更新项目

```http
PATCH /api/v3/projects/{project_id}
Content-Type: application/json
```

请求体可传字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 项目名称 |
| `description` | string | 项目说明 |
| `tags` | object | 自定义标签 |
| `is_active` | bool | 是否启用 |

## 5. 删除项目

```http
DELETE /api/v3/projects/{project_id}?force=false
```

Query 参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `force` | bool | false | 是否级联删除相关训练任务和模型版本 |

响应：

```json
{
  "ok": true,
  "message": "Project deleted"
}
```

## 6. 项目模型大小统计

### 6.1 单个项目

```http
GET /api/v3/projects/{project_id}/model-size
```

响应：

```json
{
  "project_id": 1,
  "completed_models_count": 5,
  "total_size_mb": 125.67
}
```

### 6.2 批量项目

```http
GET /api/v3/projects/model-sizes?project_ids=1,2,3
```

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `project_ids` | string | 否 | 逗号分隔的项目 ID；不传则返回全部项目 |

响应：

```json
[
  {
    "project_id": 1,
    "completed_models_count": 5,
    "total_size_mb": 125.67
  }
]
```

统计口径：只统计未隐藏且状态为 `completed` 的训练任务，并累加 `training_run_results.model_size_mb`。

## 7. 对比基线管理

对比基线用于指定项目在某个框架下的基准训练任务，供训练对比页面作为参考。

### 7.1 获取对比基线

```http
GET /api/v3/projects/{project_id}/compare-baseline?framework_key=pytorch
```

Query 参数：

| 参数 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `framework_key` | string | 是 | `pytorch` / `paddle` / `engine:<name>` |

响应：

```json
{
  "project_id": 1,
  "framework_key": "pytorch",
  "baseline_run_id": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40",
  "baseline_run": {
    "run_id": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40",
    "name": "baseline-v1",
    "status": "completed",
    "architecture_id": 2,
    "engine": "ultralytics-yolo"
  }
}
```

### 7.2 设置对比基线

```http
PUT /api/v3/projects/{project_id}/compare-baseline
Content-Type: application/json
```

请求体：

```json
{
  "framework_key": "pytorch",
  "baseline_run_id": "8ad9f1e9-0b80-4aa9-bf9c-cb84c148fd40"
}
```

### 7.3 清除对比基线

```http
DELETE /api/v3/projects/{project_id}/compare-baseline?framework_key=pytorch
```

## 8. 数据模型

### ProjectOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `project_id` | int | 项目 ID |
| `name` | string | 项目名称 |
| `description` | string? | 项目说明 |
| `standard_dataset_id` | int | 绑定的标准数据集 ID |
| `task_type` | string | 任务类型 |
| `created_by` | string? | 创建者 |
| `tags` | object? | 自定义标签 |
| `is_active` | bool | 是否启用 |
| `created_at` | datetime | 创建时间 |
| `updated_at` | datetime | 更新时间 |

### ProjectCompareBaselineOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `project_id` | int | 项目 ID |
| `framework_key` | string | 框架分组 |
| `baseline_run_id` | string? | 基线训练任务 ID |
| `baseline_run` | object? | 基线训练任务摘要 |
