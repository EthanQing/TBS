# 模型部署 API (Deployments)

> 路由前缀：`/api/v3/deployments`、`/api/v3/deployment-runs`
> 标签：`deployments`、`deployment-runs`

部署模块负责把模型版本绑定为可执行服务，并提供部署执行、API Key 生成、运行状态、日志、取消、重试和回滚能力。

## 1. 部署管理

### 1.1 获取部署列表

```http
GET /api/v3/deployments
```

Query 参数：

| 参数 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `page` | int | 否 | 1 | 页码 |
| `page_size` | int | 否 | 50 | 每页条数，1~500 |
| `project_id` | int | 否 | - | 按项目过滤 |
| `model_version_id` | int | 否 | - | 按模型版本过滤 |
| `status` | string | 否 | - | `pending` / `deploying` / `active` / `inactive` / `failed` / `deleting` |
| `is_active` | bool | 否 | - | 是否激活 |

响应：分页 `DeploymentOut`。

### 1.2 创建部署

```http
POST /api/v3/deployments
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `model_version_id` | int | 是 | 模型版本 ID |
| `name` | string | 是 | 部署名称，1~255 字符 |
| `platform` | string | 是 | `local` / `docker` / `kubernetes` / `aws` / `azure` / `gcp` |
| `config` | object | 否 | 部署配置 |
| `health_check_url` | string | 否 | 健康检查 URL |

请求示例：

```json
{
  "model_version_id": 10,
  "name": "车辆检测-生产部署",
  "platform": "local",
  "config": {
    "replicas": 1
  }
}
```

响应：`201 Created`，返回 `DeploymentOut`。

### 1.3 执行部署

```http
POST /api/v3/deployments/{deployment_id}/execute
Content-Type: application/json
```

执行部署会创建一条部署运行记录，并可生成或轮换在线推理 API Key。

请求体：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `operator` | string | 否 | `admin` | 操作人 |
| `reason` | string | 否 | - | 执行原因 |
| `rotate_api_key` | bool | 否 | true | 是否轮换 API Key |
| `conf` | float | 否 | 0.25 | 默认推理置信度阈值 |
| `iou` | float | 否 | 0.45 | 默认推理 IoU 阈值 |

响应示例：

```json
{
  "run": {
    "run_id": "ca1a6c55-0e5a-4814-90e9-f50cd5752c6c",
    "deployment_id": 1,
    "project_id": 1,
    "model_version_id": 10,
    "trigger_type": "manual",
    "status": "queued",
    "phase": "preparing",
    "current_step": null,
    "progress": 0,
    "cancel_requested": false,
    "started_at": null,
    "finished_at": null,
    "error_message": null,
    "snapshot": null,
    "created_at": "2026-06-13T03:20:00+00:00",
    "updated_at": "2026-06-13T03:20:00+00:00"
  },
  "issued_api_key": "sk-xxxxxxxxxxxxxxxx",
  "api_key_hint": "sk-xxxx...xxxx"
}
```

`issued_api_key` 只在创建或轮换时返回一次，请客户端保存。

### 1.4 获取、更新、删除部署

```http
GET /api/v3/deployments/{deployment_id}
PATCH /api/v3/deployments/{deployment_id}
DELETE /api/v3/deployments/{deployment_id}
```

更新请求体可传字段：

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 部署名称 |
| `status` | string | 部署状态 |
| `endpoint_url` | string | 在线端点 URL |
| `health_check_url` | string | 健康检查 URL |
| `config` | object | 部署配置 |
| `is_active` | bool | 是否激活 |

删除响应：

```json
{
  "ok": true,
  "message": "Deployment deleted"
}
```

## 2. 部署日志

查询部署级日志：

```http
GET /api/v3/deployments/{deployment_id}/logs?limit=200
```

新增部署级日志：

```http
POST /api/v3/deployments/{deployment_id}/logs
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `level` | string | `INFO` | `DEBUG` / `INFO` / `WARNING` / `ERROR` |
| `message` | string | - | 日志内容 |
| `data` | object | null | 附加数据 |

## 3. 回滚

### 3.1 获取回滚候选

```http
GET /api/v3/deployments/{deployment_id}/rollback/candidates
```

响应包含当前部署和可回滚的模型版本列表。

### 3.2 执行回滚

```http
POST /api/v3/deployments/{deployment_id}/rollback
Content-Type: application/json
```

请求体：

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `target_model_version_id` | int | 是 | - | 目标模型版本 ID |
| `reason` | string | 是 | - | 回滚原因 |
| `operator` | string | 否 | `admin` | 操作人 |

响应：

```json
{
  "deployment": {
    "deployment_id": 1,
    "model_version_id": 9,
    "name": "车辆检测-生产部署",
    "platform": "local",
    "status": "active",
    "endpoint_url": null,
    "health_check_url": null,
    "config": {},
    "api_key_hint": "sk-xxxx...xxxx",
    "is_active": true,
    "deployed_at": "2026-06-13T03:30:00+00:00",
    "created_at": "2026-06-13T03:00:00+00:00",
    "updated_at": "2026-06-13T03:30:00+00:00"
  },
  "event": {
    "log_id": 15,
    "deployment_id": 1,
    "created_at": "2026-06-13T03:30:00+00:00",
    "operator": "admin",
    "reason": "回退到稳定版本",
    "from_model_version_id": 10,
    "to_model_version_id": 9,
    "from_version": "v1.1.0",
    "to_version": "v1.0.0"
  }
}
```

### 3.3 获取回滚历史

```http
GET /api/v3/deployments/{deployment_id}/rollback/history?limit=200
```

## 4. 部署运行

### 4.1 获取部署运行详情

```http
GET /api/v3/deployment-runs/{run_id}
```

### 4.2 重试部署运行

```http
POST /api/v3/deployment-runs/{run_id}/retry
```

响应与执行部署类似，包含新运行记录和可能新签发的 API Key。

### 4.3 取消部署运行

```http
POST /api/v3/deployment-runs/{run_id}/cancel
```

### 4.4 获取运行日志

```http
GET /api/v3/deployment-runs/{run_id}/logs?from_seq=0&limit=1000
```

Query 参数：

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `from_seq` | int | 0 | 只返回大于该序号的日志 |
| `limit` | int | 1000 | 最大返回条数 |

### 4.5 部署运行 WebSocket

```text
ws://<host>/api/v3/deployment-runs/{run_id}/stream?from_seq=0
```

消息类型：

| type | 说明 |
|------|------|
| `snapshot` | 初始运行快照 |
| `progress` | 状态、阶段、进度变化 |
| `log` | 运行日志 |
| `done` | 运行到达终态 |
| `error` | 错误 |
| `ping` | 心跳 |

部署运行阶段：

| phase | 说明 |
|-------|------|
| `preparing` | 准备中 |
| `validate_artifacts` | 验证模型产物 |
| `materialize_runtime` | 准备运行时 |
| `smoke_test` | 冒烟测试 |
| `activate` | 激活部署 |
| `done` | 完成 |
| `failed` | 失败 |
| `cancelled` | 已取消 |

## 5. 数据模型

### DeploymentOut

| 字段 | 类型 | 说明 |
|------|------|------|
| `deployment_id` | int | 部署 ID |
| `model_version_id` | int | 模型版本 ID |
| `name` | string | 部署名称 |
| `platform` | string | 平台 |
| `status` | string | 状态 |
| `endpoint_url` | string? | 服务端点 |
| `health_check_url` | string? | 健康检查 URL |
| `config` | object? | 配置 |
| `api_key_hint` | string? | API Key 脱敏提示 |
| `is_active` | bool | 是否激活 |
| `deployed_at` | datetime? | 部署时间 |
| `created_at` | datetime | 创建时间 |
| `updated_at` | datetime | 更新时间 |

| 字段 | 类型 | 说明 |

| `status` | string | `queued` / `running` / `completed` / `failed` / `cancelled` |
| `phase` | string | 当前阶段 |
| `current_step` | string? | 当前步骤 |
| `progress` | int | 0~100 |
| `cancel_requested` | bool | 是否请求取消 |
| `started_at` | datetime? | 开始时间 |
| `finished_at` | datetime? | 完成时间 |
| `error_message` | string? | 错误信息 |
| `snapshot` | object? | 运行快照 |
| `created_at` | datetime | 创建时间 |
| `updated_at` | datetime | 更新时间 |
